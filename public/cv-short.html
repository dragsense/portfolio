How I work

Reusable feature bundles

A feature is built once and mounted on any page that needs it, scoped to that context — so the tenth feature costs less than the third, not more.

Shared types, front to back

The client and server compile against the same types. A breaking API change fails the build instead of the live site.

Shared platform layer

Tenancy, permissions, caching, logging, events, validation and file storage are built once and reused, never rewritten per feature.

Security by default

AES-256-GCM encryption in transit and at rest, CSRF tokens, CSP and HSTS headers, strict CORS, and layered auth, permission and tenant guards.

Debugging down the stack

Tracing bugs to the layer they really live in — containers, migrations, reverse proxy, DNS, mail routing, bad third-party data.

AI engineering

Built a production MCP server in NestJS with HTTP and stdio transports and typed tools. Daily Claude, Claude Code and Cursor; n8n for automation.
